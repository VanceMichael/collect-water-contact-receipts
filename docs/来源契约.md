# 资料提供方的格式

`/pier/leases.html` 的表列为船筏、短号、航线、起分钟、止分钟，区间左闭右开。网页登记是当时已知借期。`/pier/corrections.csv` 的证实精确到岸站、频段、接报编号，船筏为空代表无法证实。
`/banks/morning.json` 的 segments 的字段是岸站、频段、监听段、开始、结束和是否结束，reports 的字段是岸站、频段、监听段、开始、结束、声音片号、短号、分钟和状态。连续报文前缀有 end=false 的临时段，`/banks/relay.json` 是邻站提供的同类应答及一条对指定原站监听段的结束证明，source_key 指原站、频段和段号。相同录次以声片号及实测分钟区分，transfer.json 是代呼出单和值班确认，分别记录待核查船筏与代听范围销项的不同确认对象。
